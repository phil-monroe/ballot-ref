# Contract: Data files

- `data/discovery/proposals/<contest-stem>.yaml`: array of Proposal (see data-model.md). Committed. Strict
  zod schema (`src/schemas/proposal.ts`); unknown fields rejected.
- `data/logs/discovery-runs.jsonl`, `data/logs/source-decisions.jsonl`: append-only JSONL, committed.
- `data/reports/processing.json`: ProcessingRecord array, regenerated by `process` and review.
- `data/sources/<contest-stem>.yaml`: unchanged format; `domain_class` additionally allows `other` only with
  `tier: context`. `sources check` enforces this.
- The static site build MUST NOT read `data/discovery/` (asserted by an invariant test, like the existing
  privacy tests), so proposals and reject reasons can never appear on the published site.
- Because rejected URLs and reasons are committed, `scripts/check-private-snapshots.sh` is unaffected
  (no third-party bodies are stored; excerpts are never persisted).
